# CSC649_Setup_2024804414

## About
Counts the words and characters in a sentence typed by the user.

## How to run
- Open the project in PyCharm
- Run `main.py`
- Enter a sentence when prompted

## Testing
- **Normal sentence** (`I love data science`): 4 words, 19 characters. Passed.
- **Empty input**: shows "You did not enter a sentence." Passed.
- **Extra spaces** (`  hello    world  `): 2 words, 18 characters. Passed.

## Limitation
The character count always includes spaces, including extra spaces at the
start and end. There is no option to count letters only."# CSC649"
